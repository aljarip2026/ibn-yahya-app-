# ابن يحيى - تحويل إلى APK عبر GitHub
1. أنشئ مستودع جديد على github.com/new وارفع كل محتويات هذا المجلد (أو اسحبها بـ git push)
2. اذهب إلى تبويب Actions > Build APK > Run workflow
3. انتظر انتهاء البناء، ثم حمّل الملف من Artifacts باسم ibn-yahya-apk
4. ثبّت app-debug.apk على هاتفك (فعّل التثبيت من مصادر غير معروفة)
ملاحظة: هذه نسخة Debug. لنسخة Release موقّعة من Google Play تحتاج Keystore.
